# Описание индивидуального проекта (кратко)

См. подробный разбор с ER-диаграммами: **[ПОНЯТНОЕ_ОПИСАНИЕ.md](ПОНЯТНОЕ_ОПИСАНИЕ.md)**.

**Тема:** Горизонтально фрагментированная СУБД контура исполнения отгрузок на распределённых складских площадках.

**Суть:** два региона (WEST/EAST), на каждом primary+replica PostgreSQL; оперативка режется по `region_code`; клиент FastAPI делает CRUD и цепочку статусов отгрузки с журналом событий; чужой регион — отказ.

**Артефакты:** `docker-compose.yml`, `db/init/`, `client/`, `scripts/`, заявка в `docs/`.
